## Hello World!

Welcome to my new blog! This site is powered by [Hugo](https://gohugo.io/), a blazing-fast static site generator written in Go. 

### Why Hugo?

- **Speed**: Builds complete sites in milliseconds
- **Simplicity**: Just markdown files and YAML frontmatter
- **Portability**: Content is just plain text — no database required
- **Flexibility**: Easy to migrate hosting later (Cloudflare Pages, Netlify, VPS, etc.)

### How It Works

The workflow is straightforward:

1. **Write** content as markdown files in `content/posts/`
2. **Build** generates static HTML into the `public/` directory
3. **Preview** locally with Hugo's live-reload server
4. **Publish** via Tailscale for private access, or migrate to a public host later

### Version Control

All content is tracked in Git and hosted on [Forgejo](https://forgejo.org/) at `http://forgejo-1:3000/elyons/blog`. This gives us:

- Full history of every change
- Ability to branch and experiment safely
- A web interface for browsing code and issues
